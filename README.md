# Spam Email/SMS Detector

**Tech:** Python, Pandas, scikit-learn, TF-IDF, Logistic Regression, Streamlit.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The app trains a simple text-classification pipeline from `data/messages.csv`. The included dataset is intentionally small and only demonstrates the workflow; it is not suitable for real spam detection.
